# nosim

Core library for a real-time world simulator that scales continuously from runway pavement
to translunar space. The full design is in
[`docs/architecture/system-architecture-spec.md`](docs/architecture/system-architecture-spec.md).

This workspace holds the **engine-independent spine** of that design as two crates:

- **`nosim`** (root) — double-precision, deterministic Rust with `#![forbid(unsafe_code)]`.
  The headless `world-compiler` ingestion pipeline uses it directly.
- **`nosim-ffi`** (`ffi/`) — the C ABI the Unreal Engine 5 client links: a `staticlib` /
  `cdylib` plus a header generated by cbindgen on every build, so it can never drift.

Everything is covered by tests that assert the spec's own numbers and acceptance criteria,
and the C ABI is additionally proven by a C program compiled and run against the library.

## Layout

```
  ephem/         VSOP87D Sun–Earth and ELP 2000-82B Moon evaluators,
                 obliquity, nutation, GAST, apparent places,
                 topocentric vectors, phase, optical libration        (spec §8A)
  starfield/     Yale Bright Star Catalogue (BSC5) loader, packed
                 star buffer, Planckian-locus star colour              (spec §8A)
  timescale.rs   UTC / UT1 / TT / TDB, ΔT from leap seconds (1972–)
                 and Espenak–Meeus polynomials, Unix-time entry point  (spec §6, §8A)
  scenery/       Package manifest + validator, GeoJSON exclusion
                 masks, prioritised mount table (VFS)                 (spec §3)
  arinc424.rs    ARINC 424 PG record decoder, designators, threshold
                 bar counts, runway extrusion + grade fitting         (spec §4)
  procedural.rs  Spatial seed hash, Poisson building levels, bridge
                 pier stations, runway flattening falloff             (spec §5)

                 merge / FIFO diverge network, near-field handoff     (spec §7)
  photometry.rs  Hapke regolith BRDF, Chapman function, limb shell    (spec §8B, §8C)
  lod.rs         Altitude-band LOD governor, ECI / MCI / ICRF choice  (spec §2, §8)
ffi/
  src/lib.rs     The extern "C" surface (one wrapper per core capability)
  include/       nosim.h, regenerated by build.rs via cbindgen — do not edit
  tests/         api.rs calls the ABI from Rust; c_smoke.rs compiles and runs examples/c/smoke.c
  examples/c/    smoke.c: a plain C host driving every handle type
fixtures/        The spec's KJFK example package (scenery tests); the BSC5 catalogue
                 compiled to nosim's packed form plus a 22-line text excerpt (starfield tests)
examples/        compile_bsc5: turns the CDS catalogue text into the packed star buffer
tools/           ephem_tables.py: reference evaluator + generator for the ephemeris tables
docs/            Architecture specification
```

Each module carries its tests inline (`#[cfg(test)]`). Dependencies: `serde` and
`serde_json` for the manifest and GeoJSON formats; nothing else.

## Build and test

```sh
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all --check
cargo doc --no-deps --open
cargo build -p nosim-ffi --release   # target/release/libnosim_ffi.{a,so,dylib,dll} + ffi/include/nosim.h
```

Requires a stable Rust toolchain (edition 2024, so 1.85 or newer).

## C ABI (`nosim-ffi`)

`ffi/include/nosim.h` exposes the whole core to C and C++ under conventions chosen for an
Unreal Engine 5 host:

- Doubles for all world quantities (UE5 large-world coordinates); `repr(C)` POD structs such
  as `NosimVec3`, `NosimGeodetic`, `NosimBounds` passed and returned by value.
- Stateful objects are opaque handles — `NosimFloatingOrigin`, `NosimVfs`, `NosimPackage`,
  `NosimStarCatalog` — created by `*_new` / `*_load` and released by `*_free`. Passing `NULL`
  anywhere is safe and yields an error status, `false` or zero.
- Fallible calls return `NosimStatus`; the message behind a failure (for example the package
  validator's full report) is available from `nosim_last_error()` until the next failing call
  on the same thread.
- Strings out go into caller buffers; the return value is the size needed including the NUL,
  so `0` means "nothing" and a value above the capacity means "truncated". Array outputs take
  `(out, capacity)` and return the total available.
- Hot paths have batch forms (`nosim_ecef_to_enu_batch`, `nosim_floating_origin_to_render_batch`).

Linking from an Unreal module (`NosimBridge.Build.cs`):

```csharp
PublicIncludePaths.Add(Path.Combine(ModuleDirectory, "../../ThirdParty/nosim/include"));
string Lib = Target.Platform == UnrealTargetPlatform.Win64 ? "nosim_ffi.lib" : "libnosim_ffi.a";
PublicAdditionalLibraries.Add(Path.Combine(ModuleDirectory, "../../ThirdParty/nosim/lib", Target.Platform.ToString(), Lib));
if (Target.Platform == UnrealTargetPlatform.Win64) {
    PublicSystemLibraries.AddRange(new[] { "ws2_32.lib", "userenv.lib", "bcrypt.lib", "ntdll.lib" });
}
```

Build the library with the matching Rust target (`cargo build -p nosim-ffi --release
--target x86_64-pc-windows-msvc`, etc.) and copy `ffi/include/nosim.h` next to it. The header
is C11 and `extern "C"`-wrapped for C++.

## Star catalogue

`src/starfield` parses the CDS V/50 `catalog` text (Hoffleit & Warren 1991,
<https://cdsarc.cds.unistra.fr/ftp/V/50/>) by its ReadMe byte layout. `fixtures/bsc5/bsc5.bin`
is that file compiled to the packed form by

```sh
cargo run --example compile_bsc5 -- catalog fixtures/bsc5/bsc5.bin
```

and is what an engine would `include_bytes!`: 28 bytes per star (HR, RA, Dec, V, B−V, proper
motion), 255 KB for the 9,096 positioned stars. `Catalog::records()` derives the 16-byte
RA / Dec / V / B−V structured buffer the spec's celestial sphere binds, substituting
`DEFAULT_BV` (0.6, a solar-type white) for the 310 stars without a measured colour.

## Ephemeris tables

`src/ephem/vsop87d_earth.rs` and `src/ephem/elp82b_moon.rs` are generated — do not edit —
by `tools/ephem_tables.py` from the IMCCE distribution files (`VSOP87D.ear`, `ELP1`–`ELP36`,
from <https://ftp.imcce.fr/pub/ephem/> or the CDS mirror VI/81 and VI/79). The script is a
line-for-line port of IMCCE's `elp82b_2` Fortran and of the VSOP87 substitution rule, and it
has three subcommands:

```sh
python3 -I tools/ephem_tables.py --vsop <dir> --elp <dir> check --horizons <horizons.txt>
python3 -I tools/ephem_tables.py --vsop <dir> --elp <dir> trunc
python3 -I tools/ephem_tables.py --vsop <dir> --elp <dir> emit --out src/ephem --threshold 0.001
```

`check` proves the port against `vsop87.chk` and JPL Horizons before anything is emitted;
`trunc` measures what dropping small ELP perturbation terms costs; `emit` writes the tables.
What is checked in: the full VSOP87D Earth series (2,425 terms) and the complete ELP main
problem (2,645 terms) plus the 2,162 perturbation terms at or above 0.001″ — a measured
worst case of 0.04″ in longitude and latitude and 45 m in distance over 1900–2100 versus
the full 35,227-term series. Time arguments are TDB (TT is indistinguishable at this level).
